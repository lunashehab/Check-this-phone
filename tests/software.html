FAQ: SOFTWARE & TRACKING

1. What is a "User Agent"? ▼
It's a text string your browser sends to every website you visit. It declares "I am an iPhone running iOS 17 using Safari."
2. Can websites track me without cookies? ▼
Yes! "Canvas Fingerprinting" (shown above) creates a unique ID based on your hardware. Clearing cookies does NOT delete this ID.
3. What is an IMEI Blacklist? ▼
If a phone is reported stolen, carriers add its IMEI to a global blacklist. The phone will never connect to cellular networks again.
4. Why does my OS say "Linux"? ▼
Android is built on top of the Linux kernel. Seeing "Linux armv8" is the correct technical name for Android phones.
5. What is a "SimLock"? ▼
Carriers lock phones so they only work on their network (e.g., AT&T Only). An IMEI check reveals if you can switch carriers.
6. Is my IP Address visible? ▼
Yes. Unless you use a VPN, every website can see your IP address, which reveals your approximate city and ISP.
7. What is "WebAssembly"? ▼
It is a new technology that lets browsers run high-performance code (like 3D games or video editors) at near-native speed.
8. What is "GSX"? ▼
Global Service Exchange. It is Apple's internal database for repair history, activation dates, and iCloud lock status.
9. Can I change my User Agent? ▼
Yes, but usually only on desktop browsers using "Developer Tools." Mobile browsers generally don't allow this easily.
10. Does "Do Not Track" work? ▼
Not really. It sends a polite request to websites asking them not to track you, but most websites (including Google/Facebook) ignore it.
